# 🎮 Player Punishments [IN-GAME]

---

## ⚠️ Must-Know
- **Severe cases** → Instant punishment (no warning)
- **Mild cases** → Warning first
- Repeating offenses → **Punishment gets longer**

---

## 🔨 Permanent Ban (Severe Cases)
*Clear evidence required. Always post it in the punishment channel.*

### 🚫 Cheating
Using hacks or any unfair tools  
→ **Permanent ban**

---

### 🤝 Playing with Cheaters
Helping or teaming with cheaters for advantage. This is applied ONLY if it's obvious that they're playing with the cheater only to gain advantages.
For example: playing in a closed room with someone that uses quick ammo hacks in a boss battle match.
→ **Permanent ban (main account)**  
→ New accounts are allowed

---

### 💥 Severe Exploits
- Crashing rooms/servers  
- Getting free items/currency  
- Packet abuse  
→ **Permanent ban**

---

### 🛠️ Game File Modding
- Editing `cgd.dip` or `map.dat`  
→ **Permanent ban**

- Other files (`model.dat`, `fx.dat`)  
→ **Only banned if it gives advantage**

---

### 🌐 Server Attacks
- DDoS, mass trolling, server crashes  
→ **Permanent ban**

---

### ☠️ Malware / Hacks Distribution
- Sharing cheats, viruses, or tutorials  
→ **Permanent ban**

---

### 🔁 Ban Evasion
Using alt accounts after a ban  

- If banned for **cheating/doxxing**  
  → All alt accounts = **permanent ban**

- Other cases  
  → New accounts are allowed
